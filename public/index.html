Hardware Configuration Notes:
  • DHT22: Requires a 10kΩ pull-up resistor between 3.3V and GPIO4 DATA line.
  • DS18B20: Requires a 4.7kΩ pull-up resistor between 3.3V and GPIO5 Yellow/White DATA line.
  • Capacitive Moisture: Connect AO directly to GPIO34 (Input-only ADC1 pin). Avoid ADC2 when WiFi is active.
  • INA219: I2C address default is 0x40. SDA to GPIO21 and SCL to GPIO22.

PROBLEM: nan

DHT22 Temperature / Humidity Read Failure

If the ESP32 receives nan (Not a Number) from the DHT22, the digital timing handshake has timed out.

3.3V ───[ 10kΩ Resistor ]───┬─── DHT22 DATA (GPIO4)
                            └─── ESP32 GPIO4
PROBLEM: -127°C

DS18B20 Soil Probe Disconnection

The Dallas OneWire protocol returns exactly -127.00°C (DEVICE_DISCONNECTED_C) when the sensor is unable to reply.

3.3V ───[ 4.7kΩ Resistor ]──┬─── DS18B20 Yellow/White (GPIO5)
                            └─── ESP32 GPIO5
PROBLEM: INA219 Not Found

I2C Bus Communication Failure

If the ESP32 serial monitor reports INA219 Not Found, the I2C peripheral is not responding at address 0x40.

INA219 SCL ─── ESP32 GPIO22
